Código

Os exemplos das lições são programas Java reais, que compilam e rodam. O output citado nas lições é output capturado, não imaginado.

  • code/0001-seam/SeamDemo.java — a mesma regra bancária com e sem seam. Rode com java SeamDemo.java.
  • code/0002-deep-module/DepthDemo.java — o mesmo ledger com uma interface de seis métodos e com uma de um. Corpos de método byte-a-byte idênticos. Rode com java DepthDemo.java.
  • code/0003-interface/InterfaceDemo.java — dois ledgers com assinaturas idênticas, um deles destruindo dinheiro; e o javac chamado em tempo de execução para provar que a ordem errada não compila. Rode com java InterfaceDemo.java.
  • code/0004-adapter/AdapterDemo.java — um port com um adapter de disco e um de memória, e a JVM confirmando que a FeePolicy não subiu para a interface pública. Rode com java AdapterDemo.java.
  • code/0005-deletion-test/DeletionTestDemo.java — o deletion test executado, não imaginado: dois conjuntos de callers por caso, os dois rodando, e o programa lendo o próprio fonte para contar o que reapareceu. Rode com java DeletionTestDemo.java.
  • code/0006-dependency-inversion/InversionDemo.java — injeção com e sem inversão lado a lado, um detector de 1 interface : 1 adapter por reflexão, e os dois portões do repositório discordando sobre as mesmas quatro dependências. Rode com java InversionDemo.java.
